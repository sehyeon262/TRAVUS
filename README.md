**모두를 위한 배리어프리 AI 여행 경로 추천 서비스**

장애인과 비장애인 모두가 제약 없이 여행을 즐길 수 있도록,  
접근성 정보와 사용자 맞춤 추천을 결합한 **포용적 여행 플랫폼**입니다.

AI 기반 분석과 웹 접근성 설계를 통해  
여행지 선택부터 이동 경로까지 **실질적으로 도움이 되는 여행 경험**을 제공합니다.

> 걷는 속도가 달라도, 바라보는 높이가 달라도  
> **모두에게 같은 여행의 즐거움을**


- **개발 기간** : 2025.11 ~ 2025.12 (약 6주)
- **플랫폼** : Web 
- **개발 인원** : 2명
- **기관** : 삼성 청년 SW·AI 아카데미 14기
- **수상 내역** : 🥇 SSAFY 관통 프로젝트 최우수상

---

## 핵심 기능

- **배리어프리 여행 정보 제공**
- **TTS(Text-to-Speech) 기반 음성 안내**
- 장애 유형별 여행지 필터링
- 테마 / 커스텀 여행 코스
- AI 카메라 기반 보행 환경 인식
- 커뮤니티 기반 후기 및 정보 공유

---

## 기술 스택

### Frontend
- Vue 3 (Composition API)
- Vite
- Pinia (상태 관리)
- Vue Router
- Axios
- HTML5 / CSS3
- GSAP (애니메이션)

### Backend
- Python 3.13
- Django 5.2
- Django REST Framework
- JWT 인증 (SimpleJWT)
- MySQL

### AI / Data
- OpenAI API
- 한국관광공사 무장애 여행 API

### Tools
- Git / GitHub
- REST API

## 담당 역할 (Frontend Lead)

- AI 카메라 기반 이미지 분석 기능을 구현하여,
  이미지 업로드부터 AI 분석 결과 반환까지 전체 파이프라인 개발
- Django 기반 백엔드에서 AI 관련 앱을 설계하고,
  REST API 및 직렬화 로직 구현
- 프론트엔드 로그인·회원가입 화면 및 UI 구조 개선
